# Fixture provenance

The API fixture set is recorded from W5's samples in `.agents/tasks/swarm/fixtures/webapi/` and the contracts in `.agents/tasks/metro-leg-contract.md` and `.agents/tasks/swarm/contracts.md`. No raw data, vehicle identifiers, or invented API fields are included. The mock layer intentionally fails unmatched requests so new fixtures must be recorded before use.

Recorded W5 sample names: `capabilities.json`, `live-buses.json`, `next-buses.json`, `route-detail.json`, `routes-search.json`, `stops-all.json`, and `stops-nearby.json`.
